# ORE Project — Allocation Algorithm Analysis

Exploratory analysis, cost-optimisation model, and predictive model for a South African
fulfilment network. Built on a single day of allocation logs (2024-01-05).

> **Full findings:** open `report.html` in a browser.

## Using the allocator programmatically

```python
from src.data_loader import DataLoader
from src.cost_engine import CostEngine
from src.allocator   import Allocator, precompute_inventory_costs

loader  = DataLoader()
orders  = loader.load_orders()
items   = loader.load_items()
inv     = loader.load_inventory()

ce          = CostEngine()
inv_prepped = precompute_inventory_costs(inv, ce)

# Greedy solver (fast, ~60 ms/order)
alloc = Allocator(ce, use_exact=False, max_split_k=3)

# Exact MIP solver (optimal, ~70 ms/order)
# alloc = Allocator(ce, use_exact=True, max_split_k=3)

results = alloc.allocate_all(orders, items, inv_prepped)
# → DataFrame with columns: order_idx, order_id, n_parcels, total_cost,
#                            n_assigned, n_cancelled
```

## Key domain facts

- **One parcel per physical facility.** All items in an order allocated to the same
  facility ship together as one parcel (one courier charge).
- **DC virtual branches.** Each physical DC (`dc_a`, `dc_b`) has multiple virtual
  branch numbers (one per brand/trading company). These are merged into a single
  physical key; stock is **summed** across virtual branches.
- **courier_b** may only collect from `dc_b` branches. `courier_a` may not serve `dc_b`.
- **courier_c** eligibility requires `FacilityCourierCActive = True` **and** the
  customer's address within **20 km** of any courier_c-active facility (haversine check).
  All 29 courier_c facilities are Cape Town stores.
- **Route LMR** is a route property (origin hub × destination hub), not a facility
  property. Resolve via postal code → `courier_post_code_mapping.csv`.
- **Alternative SKU.** When `alternative_sku ≠ primary_sku`, both allocators try the
  primary SKU first. The alternative is only used if primary stock is insufficient.
  All units of a single order line must use the same SKU (no partial mixing).
